# perezkabagambe.github.io

This repository only exists so that the Fleet Manager Android app can prove it belongs to this website.
Android looks for `/.well-known/assetlinks.json` at the top of the address, so the file has to live in the repository GitHub publishes there.
The file holds the app's package name and the public fingerprint of its signing certificate. It contains no code, data or secrets.

The app itself lives in https://github.com/perezkabagambe/fleet-manager and is published at https://perezkabagambe.github.io/fleet-manager/.
